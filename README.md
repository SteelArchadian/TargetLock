# Target Lock

Zelda-style Z-targeting for NeoForge 1.21.1. Client-side only; works on any server. **Version 0.4.0 (alpha).**

> **Alpha:** usable, but expect rough edges. **Feedback, bug reports and feature ideas are very welcome**: please post them in **[Issues](https://github.com/SteelArchadian/TargetLock/issues)**. Every one gets read, and feature requests are genuinely encouraged.

- **Z** (rebindable): lock onto the best mob in view. The view turns toward it and stays on it; WASD becomes strafing around it.
  Toggle or hold mode. **.** / **,** or the **mouse wheel** switch to the next target right / left. Press Z again to release.
- The lock breaks when the target dies, moves past the break range, or stays out of sight longer than the grace time.
- Optional "Cycle reticle theme" key (unbound by default) to browse themes in game.
- Settings: Config Panel (or NeoForge's screen if Config Panel is absent): range, break range, acquire cone, priority,
  which mobs (hostile / neutral / passive / players / pets / blacklist), camera speed, pitch tracking, aim height,
  cinematic bars, crosshair hiding, reticle theme, colour override, size, opacity, animation speed, pop-in.

## Reticle themes
Built in: `zelda` (four triangles circling the target, Ocarina style) and `arrow` (hover arrow above the head, Breath of the Wild style).
The reticle scales with the creature's size (toggle: Scale with target); `Ring tightness` hugs or loosens the circle; `Color override` takes #RRGGBB.

Add your own with a resource pack: `assets/<namespace>/reticles/<name>.json`, select it as `<namespace>:<name>`.
```json
{ "name": "My theme", "fit_padding": 6,
  "layers": [ { "texture": "ns:textures/reticle/x.png", "size": 24, "count": 4, "radius": 30, "radius_pulse": 4, "pulse_speed": 1.5,
    "orbit_speed": 0, "spin": 0, "orient": "radial", "placement": "orbit|corners", "anchor": "center|above|feet",
    "y_offset": 0, "bob": 0, "bob_speed": 1, "flap": 0, "scale_pulse": 0, "fit": 0,
    "tint": true, "color": "#FFD22E", "alpha": 1, "additive": false } ] }
```
Textures are drawn 64x64-based, white art is tinted by `color` (or the player's colour override when `tint` is true).
`fit` scales a single layer to the target's on-screen size, or, with `count` > 1, sets the orbit radius from it.
`placement: corners` puts four copies of a top-left corner texture on the target's screen rectangle.

Built-in textures are generated by `tools/gen_textures.py`. Debug: `-Dtargetlock.test=true` auto-locks and steps through themes.

Build: `gradlew build`. It compiles against Config Panel (an optional in-game settings library), which must be in your local Maven repository.

## Bow auto-aim (0.3.0)
While locked, drawn bows aim at the target: the view tilts to the ballistic arc, optionally leading moving targets. Settings (Bow aim): Auto-aim bows, Lead moving targets, Aim accuracy (1 = perfect, lower drifts). Retarget when target dies is now on by default.
